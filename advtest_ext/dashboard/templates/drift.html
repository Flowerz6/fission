Attacker-goal drift

The attacker LLM is told to escalate freely; left unchecked it softens its own objective or drops the injection mechanism. A per-turn intent check (separate from the success judge) flags off-mechanism turns and prunes a branch after repeated drift — TAP's off-topic prune, lifted to the conversation level.

Platform / UI drift

The deployed product moves: the side panel doesn't mount, a "Resolve suggestions" modal blocks the composer, a streamed reply renders late. The Replayer's observe–verify–re-act loop absorbs these in-Run so a UI change slows a run rather than breaking it.
